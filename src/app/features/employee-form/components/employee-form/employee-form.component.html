Reactive Forms API Reference

Where each Angular Reactive Forms API is used and why
FormControlUsed for single-value fields like firstName, email, and password.
FormGroupUsed to group personalInfo, professionalInfo, and accountInformation.
FormArrayUsed for educationDetails, workExperience, and skills.
FormBuilderCreates the full nested form tree with minimal boilerplate.
NonNullableFormBuilderUsed in the non-nullable demo form for strict-typed primitive values.
ReactiveFormsModuleProvides directives such as formControlName, formGroupName, and formArrayName.
Typed Reactive FormsThis form uses strongly typed controls and groups to keep values safe.
AbstractControlUsed in custom validators and central validation messages.
FormControlNameApplied to all inputs to bind DOM elements to form controls.
FormGroupNameUsed to group logical sections like personal and professional information.
FormArrayNameUsed for dynamic sections that can add or remove records.
FormControlDirectiveUnder the hood, each input binds to a form control via Angular directives.

Form State Management

valid, invalid, pending, pristine, dirty, touched, submitted
valid{{ form.valid }}
invalid{{ form.invalid }}

disabled{{ form.disabled }}

touched{{ form.touched }}
untouched{{ form.untouched }}
submitted{{ submitted() }}

dirty vs touched: Dirty means the user changed the value. Touched means the user interacted with the control and then moved away.

pristine vs untouched: Pristine means no changes have been made. Untouched means the control has not been focused.

valid vs pending: Valid means all validation checks passed. Pending means an async validator is still running.
